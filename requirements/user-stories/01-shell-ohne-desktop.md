# Shell ohne Desktop

Als Nutzer möchte ich eine Wayland-Oberfläche, die selbst die Desktop-Umgebung ist, damit neben dem sichtbaren Inhalt kein eigener Desktop liegt.

## Akzeptanz

- Die Oberfläche ist ein Wayland-Compositor.
- Es gibt keine Schreibtischfläche mit Symbolen oder freiem Hintergrund.
- Sichtbar ist immer ein Inhalt.
