# Sprache per Schalter

Als Nutzer möchte ich die Sprachsitzung mit F1 an- und ausschalten, damit ich sprechen kann, ohne die Taste zu halten.

## Akzeptanz

- Ein Druck auf F1 schaltet die Sitzung an. Der nächste Druck schaltet sie aus.
- Die Taste bleibt dabei nicht gedrückt.
- Eine gehaltene Taste löst den Wechsel nur einmal aus.
- Solange die Sitzung an ist, kann ich mehrere Äußerungen hintereinander sprechen. Die Realtime-API grenzt sie voneinander ab.
- Ein Aufwachwort gibt es nicht.
- F1 erreicht das Fenster unter der Shell nicht.
- Solange Ton das Gerät verlassen kann, zeigt die Oberfläche das an.
- Aus heißt, dass kein Ton mehr an die API geht.
- Ohne Verbindung lässt sich die Sitzung nicht einschalten, und die Oberfläche nennt den Grund.
- Dieselbe Schaltfunktion sitzt sichtbar in der Leiste und gilt für die Maus.
