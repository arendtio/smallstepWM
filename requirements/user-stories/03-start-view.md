# Start view

As a user, I want a fixed entry that shows a resting surface, so that this surface takes the place of a desktop background.

## Acceptance

- The strip has a start entry.
- Selecting it shows a surface drawn by the shell.
- The browser is not started in order to show that surface.
- The first version of that surface is a gradient painted by the shell. It does not decode an SVG, PNG, or AVIF.
- It stands in place of a desktop background.
