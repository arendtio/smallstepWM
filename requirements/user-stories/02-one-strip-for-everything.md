# One strip for pages and windows

As a user, I want web pages and other windows in the same strip, so that the tab list and the window list are the same thing.

## Acceptance

- The strip is vertical and sits on the left edge.
- At rest it shows icons.
- Web content and foreign windows are entries in the same strip.
- When the pointer is over the strip, it grows wider, overlays the content, and shows labels.
- The content underneath is not reflowed.
- A click on an icon selects that entry.
