# Usable without a network

As a user, I want to set up Wi-Fi with the mouse even when the voice session is unreachable, so that a missing network does not lock me out of the machine.

## Acceptance

- Scanning, connecting, disconnecting, and turning Wi-Fi on and off work with the mouse.
- No API connection is required for that.
- Switching between strip entries works with the mouse and without a voice session.
