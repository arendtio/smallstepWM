# Usable without voice

As a second person, I want to browse with mouse and keyboard without knowing the voice feature, so that the machine does not depend on the API.

## Acceptance

- The machine is an experiment first.
- Browsing, switching entries in the strip, and setting up Wi-Fi work without a voice session.
- Voice is an additional path.
- Mouse use is understandable to someone used to an ordinary desktop.
