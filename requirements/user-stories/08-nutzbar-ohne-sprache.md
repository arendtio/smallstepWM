# Nutzbar ohne Sprache

Als zweite Person möchte ich mit Maus und Tastatur browsen können, ohne die Sprachfunktion zu kennen, damit das Gerät nicht an der API hängt.

## Akzeptanz

- Das Gerät ist zuerst ein Versuchsgerät.
- Browsen, der Wechsel in der Leiste und das Einrichten des WLAN gehen ohne Sprachsitzung.
- Die Sprachfunktion ist ein zusätzlicher Weg.
- Die Mausbedienung ist so weit verständlich, dass eine Person mit Erfahrung an einem gewöhnlichen Desktop sie benutzen kann.
